开启后，手机与电脑需要连接同一个 Wi-Fi。

用手机相机扫码，或手动输入上面的地址；登录时使用电脑上创建的同一个账号。

  • 只在可信的 Wi-Fi 下开启；同一网络中的其他人可能访问页面内容
  • 桌面版通过 HTTP 明文传输，不做加密；离开家庭或办公室网络后请关闭
  • 手机浏览器无法安装为应用或离线使用（HTTP 限制），功能本身不受影响
  • 数据库只监听本机回环地址，手机无法直接连接 PostgreSQL
  • 首次开启时 Windows 可能弹出防火墙授权，请允许“专用网络”

关闭开关或退出程序后，手机会立即失去访问；再次开启需要重新登录。
